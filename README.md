# Tienda Tecnológica

Sitio estático en HTML, CSS y JavaScript, preparado para publicarse con GitHub Pages.

## Publicar en GitHub Pages

1. Sube estos archivos y la carpeta `imagenes` a la raíz de un repositorio de GitHub.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda los cambios.
5. Espera a que GitHub Pages termine la publicación; la dirección aparecerá en esa misma sección.

La página de inicio es `index.html`. El formulario de contacto solo muestra una confirmación en el navegador; para enviar correos hace falta conectarlo a un servicio o servidor.
